# Admin Guide

## Overview

Admin panel is available at /admin.

## Sections

### Dashboard
- Overview of orders, reservations, and reviews
- Quick stats and recent activity

### Menu
- Manage menu items
- Update prices and images
- Add/remove items

### Inventory
- Track stock levels
- Low stock alerts
- Deduct stock on orders

### Promos
- Create promo codes
- Set discount types: percentage, fixed, item
- Limit max uses and validity dates

### Staff
- Add/remove staff members
- Assign roles: admin, manager, staff
- Manage access

### Reviews
- Approve/reject customer reviews
- Reply to reviews

### Reports
- Export CSV: orders, staff, inventory
- View analytics

### Settings
- Restaurant info
- Contact details
- Opening hours

## User Roles

- admin: full access
- manager: menu, inventory, orders
- staff: POS, orders, reservations
